01 — About

Three disciplines, one way of working

I'm a full-stack software engineer, certified by PLP Africa, building web platforms from the interface a user touches down to the database that holds their data. My focus is the backend: the part institutions rely on but rarely see — authentication and security, scalability, caching with Redis, load balancing, API design, and payment integration.
